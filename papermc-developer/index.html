papermc-developer

Minecraft の PaperMC（Paper・Folia・Velocity）のプラグインを、AI と一緒に作る・直す・動かして確かめる・配るためのスキルです。日本語で「〜するプラグインを作って」「エラーを直して」と頼むと、AI がこのスキルを使って作業します。Paper 1.7.10 から 26.x まで、どの版向けにも作れます。

要るもの

  • AI と会話できる開発道具（Claude Code、Codex、Antigravity など）
  • JDK: Gradle を動かす Java 17 以上。テストサーバーには、その版が動く Java（1.16.5 以前は 8、1.17〜1.20.4 は 17、1.20.5〜1.21 は 21、26.x は 25）。無ければ、AI が確認してから Eclipse Temurin を入れます。
  • PowerShell: Windows は最初から入っている 5.1 で動きます。macOS / Linux では PowerShell 7（pwsh）を入れてください。
  • テストサーバーを動かすときだけ、Minecraft の EULA への同意（はじめに AI が聞きます）

Gradle や Paper のサーバーは、スクリプトが要るときに公式から取ってきます。

入れ方

Claude Code

プラグインのプロジェクトのフォルダ（これから作るなら空のフォルダ）で Claude Code を開いて:

claude plugin marketplace add ukagaka-irono/papermc-developer
claude plugin install papermc-developer --scope project

入れたら、Claude Code をいったん終了して開き直します（入れた直後のセッションには読み込まれません）。claude plugin list に papermc-developer が出れば入っています。

--scope project はいまのプロジェクトだけ（.claude/settings.json に書かれ、リポジトリで共有されます）、--scope user はどのプロジェクトでも、です。消すときは claude plugin uninstall papermc-developer --scope project（入れたときと同じ --scope）。

Codex / Antigravity など

GitHub の Code → Download ZIP で落として展開し、中の skills/papermc-developer/ を、プロジェクトの .agents/skills/ に置きます。置いたら、いったん終了して開き直します。

プロジェクト\
  .agents\
    skills\
      papermc-developer\
        SKILL.md
        scripts\
        references\
        templates\
  src\
  build.gradle.kts

どのプロジェクトでも使うなら、Codex は %USERPROFILE%\.agents\skills\、Antigravity は %USERPROFILE%\.gemini\antigravity\skills\ に置きます。

使い方

日本語でそのまま頼みます。例えば:

セットアップして
夜をスキップする投票のプラグインを作りたい
Folia でも動くようにして
Velocity のプラグインを作って
/home コマンドを足して
チェックして
サーバーで動かして見せて
配布用の jar を作って
Paper を最新にして

要る資料とスクリプトは、AI が自分で読んで使います。何ができるかは「できる？」と聞けば答えます。すでにあるプラグインで使うなら、まず「セットアップして」と頼むと、コードから PLUGIN.md を下書きします。

プロジェクトに残るもの

スキルはプロジェクトにスクリプトをコピーしません。置くのは次のファイルだけです。

  • PLUGIN.md: そのプラグインのこと（何をするか、対象の版、コマンドと権限、設定、決まり、確かめ方）。AI が作業の前に読みます。
  • AGENTS.md、CLAUDE.md: PLUGIN.md を読むこと、スキルを使うことだけを書いた短い案内
  • .gitignore、.gitattributes、.editorconfig（無いときだけ）
  • .github/workflows/check.yml、release.yml（任意）

落としてきた Gradle やサーバーの jar、テストサーバー、設定は、%LOCALAPPDATA%\papermc-developer に置かれます（PAPERMCDEV_HOME で変えられます）。

テストサーバー

ふだん使っているサーバーとは別に、プロジェクトごとのテスト用サーバーを作ります。127.0.0.1 だけで待ち受けるので、ほかの PC からは入れません。自分のクライアントで localhost に入って触れます。AI は RCON でコマンドを送って結果を見ます。

自分のターミナルでコンソールを触りたいときは、ひな形に入っている ./gradlew runServer も使えます。

許可の確認を減らす

Claude Code は、スクリプトを実行するたびに許可を聞きます。読み取りや検査だけのスクリプトは、スキルを使っているあいだは許可してありますが、それ以外のときも聞かれたくなければ .claude/settings.json の permissions.allow に足します。

{
  "permissions": {
    "allow": [
      "Bash(powershell -NoProfile -ExecutionPolicy Bypass -File *papermc-developer*scripts/doctor.ps1*)",
      "Bash(powershell -NoProfile -ExecutionPolicy Bypass -File *papermc-developer*scripts/check.ps1*)",
      "Bash(powershell -NoProfile -ExecutionPolicy Bypass -File *papermc-developer*scripts/server-log.ps1*)"
    ]
  }
}

run-server.ps1 はサーバーを起動し、rcon.ps1 はサーバーにコマンドを送ります。これを許可に入れるかは、そのつもりで決めてください。

更新

  • Claude Code: claude plugin marketplace update papermc-developer のあと claude plugin update papermc-developer。そのあと Claude Code を開き直します。
  • フォルダのコピー: AI に「スキルを更新して」と頼むか、ZIP を落とし直して置き換えます。

このスキルにバージョン番号はなく、GitHub の最新のコミットを追います。
