HANNYOU-Plugin（汎用プラグイン）

Paper サーバー向けのプラグインです。スペクモード（/hannyou spec）のために作りました。ほかの機能はおまけで、プレイヤーに「役職」を付けて装備・持ち物・ポーション効果を配る Knights Editor が入っています。

入れ方

  1. Releases から HANNYOU-Plugin-<版>-all.jar を落とします。
  2. サーバーの plugins/ に置きます。
  3. サーバーを起動します。

コマンドと GUI は、OP だけが使えます（コンソールからも使えます）。OP でないプレイヤーには、コマンド自体が出ません。

スペクモード

観戦や進行役に向けた、特別なクリエイティブモードです。対象を省くと自分になります。

/hannyou spec [対象]
/hannyou unspec [対象]
  • 体・装備・持っている物・名前が、ほかのプレイヤーから見えなくなります（管理者も含む）。スペク中の人どうしは半透明で見えます。タブリストには出たままです。
  • プレイヤーや Mob を押したり押されたりせず、矢などもすり抜けます。感圧板・トリップワイヤー・スカルクセンサーも反応しません。
  • ブロックを壊す・置く、アイテムを捨てる・拾う、攻撃、乗り物に乗る、はできません。ダメージも受けません。
  • 飛べますが、クリエイティブインベントリからアイテムは取り出せません。
  • 解除すると、スペクを始めたときの持ち物に戻ります。
  • ログアウトや再起動をまたいでも続きます。スペク中はゲームモードを変えられません。

見えなくするために、スペク中の人は hannyou_spec というチームに入ります。もとのチームには、解除したときに戻ります。

役職

役職は、装備 5 か所・インベントリ 27 枠・ホットバー 9 枠・ポーション効果（I〜III）をまとめたものです。/hannyou knights editor でエディタが開きます。3 ページあって、下の矢印で切りかえます。

  1. 1 ページ目: 左に頭・胴・脚・足・オフハンドのアイテムを置きます。右で role id（半角英数字とアンダースコア）・アイコン・表示名を決めます。表示名には &c などのカラーコードが使えます。
  2. 2 ページ目: 上 3 段がインベントリ、4 段目がホットバーです。「手持ちから取り込み」で、いまの持ち物をそのまま入れられます。
  3. 3 ページ目: ポーションをクリックするたびに、なし → I → II → III → なし と変わります。
  4. 「保存」を押すと反映されます。「閉じる」は保存しません。

プレイヤーに付けるときは give です。

/hannyou knights give @a warrior     # 全員に付ける
/hannyou knights give Steve knight   # 一人に付ける
  • 付けると role id のスコアボードタグが付き、装備・持ち物・効果が配られます。インベントリは役職の中身に置き換わります。
  • 効果は時間無制限で、牛乳や不死のトーテムでは消えません。
  • 別の役職に変えると、前の役職の効果は外れます。役職を消すと、持っている人からタグと効果が外れます（アイテムは残ります）。

/hannyou knights list の一覧では、左クリックで編集、右クリックでコピー、Shift + 左クリックで試着、コンパスで検索、下の剣で新しく作れます。

試着

役職を自分に一時的に当てて、見た目や効果を確かめられます。一覧の Shift + 左クリック、エディタの「試着する」、/hannyou knights list <role id> の【試着】から使えます。チャットの【試着を終了】で元に戻ります。ログアウト・リスポーン・プラグインの停止でも戻ります。

試着中にアイテムを捨てたりチェストに入れたりすると、アイテムが増えます。試着は信頼できる管理者だけが使う前提です。

コマンド

/hannyou や /hannyou knights だけを打つとヘルプが出ます。<対象> にはプレイヤー名か、@a @s @p @r などを書きます。

コマンド説明
/hannyou spec [対象]スペクモードにする
/hannyou unspec [対象]スペクモードを解除する
/hannyou knights list役職一覧の GUI を開く
/hannyou knights list <role id>役職の中身と【編集】【試着】【削除】をチャットに出す
/hannyou knights editor [role id]役職を作る。role id を付けるとその役職を編集する
/hannyou knights give <対象> <role id>役職を付ける
/hannyou knights remove <role id>削除の確認画面を開く
/hannyou reloadconfig.yml を読み直す

設定

plugins/HANNYOU-Plugin/config.yml です。変えたら /hannyou reload で反映されます。

# 役職の作成・編集・削除などをサーバーのログと OP のチャットに記録する
log-role-changes: true

settings:
  # 登録できる役職の最大数 (-1 = 無制限)
  max-roles: -1
  # 参加時に役職の装備・インベントリを再配布する (false の場合はポーション効果のみ再適用)
  reapply-items-on-join: true

役職のデータは knights-role.yml です。手で直すときは、サーバーを止めてからにしてください（動いている間に直すと、次の保存で上書きされます）。uid は変えないでください。

ビルド

./gradlew build

build/libs/ に jar ができます。./gradlew runServer でテスト用のサーバーが起動します（はじめは run/eula.txt で EULA に同意します）。
