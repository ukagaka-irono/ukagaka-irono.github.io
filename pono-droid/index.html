pono-droid

伺か（ukagaka）のゴーストを Android で動かすベースウェアです。ゴーストをほかのアプリの上に常駐させます。SHIORI は YAYA・里々・華和梨・Kagari を Android 向けにビルドして使っています。

リポジトリ ・ Releases ・ Android 8.0 以上 ・ Apache-2.0

開発中です。動作確認は moto g05（Android 15）と、YAYA 製のゴースト 1 体で行っています。

できること

  • .nar からゴーストとバルーンをインストール
  • ホーム画面やほかのアプリの上に、キャラクター（\0 / \1）と吹き出しを表示
  • シェルの透過（PNG のアルファ / .pna / 左上の色）、surfaces.txt の element と SERIKO（新旧両形式）
  • さくらスクリプトの再生（文字送り、ウェイト、選択肢、\![raise,...] など）
  • SSP 互換のネットワーク更新（updates2.dau / updates.txt）
  • 辞書の文字コードは UTF-8 と Shift_JIS（CP932）
  • ゴーストは 3 体まで同時に動かせます

対応しているイベントとタグの一覧は、README の「SSP との互換性」にあります。

入れ方

  1. Releases から APK を落としてインストールします。まだ版が出ていないときは自分でビルドしてください。
  2. 起動して、「他のアプリの上に重ねて表示」を許可します。常駐中の通知から終了・更新するので、通知の許可も求められます。

使い方

  1. 「.nar をインストール」からゴーストの .nar を選びます。
  2. 一覧の「起動」を押すと、ゴーストが出てきます。
  3. 2 体目からは、一覧の「一緒に起動」か、ゴーストのメニューの「ほかのゴーストを呼ぶ」で起動します。一覧の「起動」は、そのゴーストだけを動かします。
  4. 終わるときは、通知の「終了」かアプリの「終了」です。

アプリの「設定」で、読み上げ・SSTP・壁紙・カレンダー・マイク・メールなどを使うかどうか選べます。どれも最初はオフです。カレンダーとマイクは、選んだときに許可を求めます。

操作

メニューの開き方はゴーストによって違います（ダブルタップ、3 回タップなど）。右クリックは長押し、中クリックは 2 本指で叩くのが代わりです。

操作動き
キャラクターをタップOnMouseClick。続けて叩くと OnMouseDoubleClick、3 回目以降は OnMouseMultipleClick
キャラクターをドラッグ移動。位置は覚えておきます
当たり判定の上で指を動かす移動せずに、なでる（OnMouseMove）
当たり判定の上をさっと払うOnMouseGesture（8 方向）
2 本指で上下になぞるOnMouseWheel
吹き出しをタップ\x の待ちを進める。話し終わっていれば閉じる
選択肢やリンクを長押しカーソルを乗せたのと同じ。離すと選ばずに外れる
ほかのアプリで「共有」→「ゴーストに渡す」ファイルなら OnFileDrop2（.nar ならインストール）、文字なら OnTextDrop、URL なら OnURLQuery
長押しメニューの「隠す」キャラクターを隠す。通知の「表示」で出し直す
長押しメニューの「位置を戻す」OnResetWindowPos。ゴーストが答えなければ最初の位置に戻す
長押しメニューの「消去」本当に消すかバルーンで確かめてから、ゴーストを消す
通知の「ネットワーク更新」起動中のゴーストを更新

キー入力でメニューを開くゴーストは、スマートフォンでは操作できません。

できないこと

  • 美坂・偽林檎など、ほかの SHIORI のゴーストは動きません。
  • SAORI（YAYA の LOADLIB など）、YAYA の EXECUTE、Lua の C モジュール・os.execute・io.popen は止めています。ゴーストにネイティブコードやシェルを動かさせないためです。
  • シェル単体の .nar は入りません。
  • ネットワーク更新で変わったシェル画像は、次の起動から反映されます。
  • Android の制約で、キャラクターの透明な部分もタッチを受け取ります。

辞書が読み書きできるのは、そのゴーストのフォルダの中だけです。辞書が無限ループして 60 秒答えないときは、SHIORI のプロセスを止めてゴーストを閉じます。

入力の箱に打った文字は、ゴーストにそのまま渡ります。ほかのサービスのパスワードなどは入れないでください。

ビルド

JDK 17、Android SDK（compileSdk 37）、Android NDK 29.0.14206865 と CMake、Git が要ります。NDK と CMake は、SDK のライセンスに同意していればビルドのときに自動で入ります。

SHIORI はサブモジュールなので、--recurse-submodules を付けて取ってきます。

git clone --recurse-submodules https://github.com/ukagaka-irono/pono-droid.git

すでにクローンしてあるなら:

git submodule update --init --recursive

local.properties に sdk.dir=... を書くか、ANDROID_HOME を設定してからビルドします。

./gradlew :app:assembleDebug

APK は app/build/outputs/apk/debug/app-debug.apk にできます。デバッグ版は開いてすぐの動きがカクつくので、ふだん使うなら次のほうがいいです（中身はリリースと同じで、デバッグ用の鍵で署名した版。データを残したまま入れられます）。

./gradlew :app:installBenchmark

テストは ./gradlew :baseware:test です。
