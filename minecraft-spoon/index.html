Spoon（MinecraftSpoon）

Minecraft 1.7.10 の Minecraft Forge 10.13.4.1614 をもとにしたものです。Forge と FML のパッケージ・mod ID・版の数字はそのまま残してあるので、いまある 1.7.10 の Forge の mod が、そのまま読みこめます。そのうえで、日本語入力（IME）を使いやすくしたり、看板にカーソルを付けたりしています。

Forge から変えたところ

  • 日本語・中国語・韓国語の IME を入れたままでも、WASD などで動けます（下で説明）。IME で打った文字は、チャット・看板などの入力欄に届き、変換の窓はカーソルのところに出ます。
  • 看板に動かせるカーソルが付きます（矢印キー・Home / End・Delete）。行の途中にも文字を入れられ、1 行には板に収まる文字だけが入ります。
  • 全角の英字（ｋ など）の幅を、描いている幅どおりに数えるので、それを含む中央ぞろえの文字が左にずれません。
  • mod の一覧を Mod Menu 風にしています。左に検索・並べかえ・ロゴのアイコンと印、右に説明（Website と Config のボタン、押せるリンク、流れる文字）があり、「mods フォルダを開く」ボタンもあります。Forge のもとの一覧（GuiModList）は変えずに残してあるので、それを広げている mod（EnderCore など）も動きます。
  • タイトル画面から Minecraft Realms をなくし、その場所に横長の「Mods」ボタンを置いています。
  • 起動が速くなります（mod を探すときにメソッドの中身を読まない）。読みこみの段階ごとに、かかった時間を「Spoon startup: …」としてログに出します。
  • タイトル画面と F3 には「Spoon <版> (Forge 10.13.4.1614)」と出ます。クライアントとサーバーのブランドは fml,forge,spoon です。
  • Forge の更新の確認はしません（Spoon にはまだ更新のサーバーがありません）。新しい版は Releases で知らせます。

日本語入力

Windows で、文字の入力欄を選んでいないあいだは、IME をゲームの窓から外します。そのため、IME をオンにしたままでも WASD などのキーがそのまま効きます。チャットや看板を開くと、IME で日本語を打てます。

この動きがいらないときは、config/forge.cfg の imeControl を false にします。

手に入れる

Releases から、使い方に合うものを落とします（ファイル名は spoon-1.7.10-10.13.4.1614-spoon1.0.0-beta.1-…）。Forge 1.7.10 と同じく、Java 8 で動かします。

ファイル使いみち
…-prism.zipPrism Launcher のインスタンス。いちばん手軽で、Spoon はこれで試しています（下で説明）
…-installer.jarForge 1.7.10 のインストーラーを Spoon 用にしたもの
…-universal.jarSpoon の jar そのもの。手で入れるとき用
…-changelog.txtForge から変えたことの一覧

リリースのページに、それぞれの SHA-256 も載せています。

Prism Launcher で遊ぶ

  1. Releases から …-prism.zip を落とします（自分で作るときは、ビルドの環境で .\gradlew.bat packagePrism）。
  2. Prism Launcher で「インスタンスを追加」→「インポート」を開き、その zip をえらびます。
  3. Minecraft 1.7.10 とライブラリは、Prism が自分で落としてきます。あとは、ふつうのインスタンスと同じように起動します。
  4. mod は、インスタンスの mods フォルダに入れます。ゲームの中の mod の一覧にある「Open Mods Folder」でも開けます。

Prism が Java 8 をえらばないときは、インスタンスの設定で Java 8 を指定します。

Spoon は Prism の一覧には入っていないので、zip の中に Spoon の部品（patches/io.github.ukagaka-irono.spoon.json）を入れてあります。

公式ランチャーで遊ぶ

  1. 公式ランチャーで、Minecraft 1.7.10 を一度起動します。
  2. …-installer.jar を Java 8 で動かし、「Install client」をえらびます。
  3. ランチャーに Spoon という起動構成ができます。

ビルド

要るもの:

  • JDK 8。Minecraft 1.7.10 と ForgeGradle 1.2 は、新しい JDK ではビルドできません。
  • はじめのセットアップのときのインターネット（Gradle・ForgeGradle・Minecraft・MCP のファイルを取ってきます）。

Gradle は、wrapper が取ってきます（Gradle 4.10.3）。Gradle は上げないでください。使っている ForgeGradle（GTNewHorizons の 1.2.13）が、Gradle 5 でなくなった機能を使っています。

  1. spoon ブランチを取ってきます。 
    git clone -b spoon https://github.com/ukagaka-irono/MinecraftSpoon.git
cd MinecraftSpoon
  2. JAVA_HOME を JDK 8 にします（PowerShell の例）。 
    $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-8.0.502.7-hotspot"
    macOS / Linux では export JAVA_HOME=/path/to/jdk8 です。
  3. 作業場所を作ります（Minecraft を逆コンパイルして、FML と Forge のパッチを当てます）。 
    .\gradlew.bat setupForge
  4. 作りたいものをビルドします。 
    .\gradlew.bat packageUniversal packageInstaller   # ユニバーサル jar とインストーラー
.\gradlew.bat packagePrism                        # Prism Launcher のインスタンス
    どれも build/distributions にできます。

macOS / Linux では .\gradlew.bat のかわりに ./gradlew を使います。

開発するとき

  • 作業場所からクライアントを動かす: .\gradlew.bat runClient（名前を決めるなら -PmcUsername=<名前>）
  • eclipse/Forge で Minecraft のクラスを直したら、gradlew genPatches でパッチを作り直します。直すつもりのなかったパッチまで変わることがあるので、意図したものだけを残して、ほかは git で戻してください。
  • Eclipse を使うときは、ワークスペースをリポジトリの中の eclipse フォルダにします。

手を入れるときの決まりは docs/CONTRIBUTING.ja.md にあります。いまある Forge の mod が動くよう、net.minecraftforge / cpw.mods.fml のパッケージと「Forge」「FML」の mod ID は変えません。
