NakkuntMovieMaker

動画編集ソフトです。一般的な動画編集と、ゆっくり解説動画を最初から最後まで作るための機能が入っています。0.0.2 から、GPU（Vulkan）で描き、色の管理とプロキシ編集もできるようになりました。

0.0.2 β（2026年11月8日） ・ Windows 10・11（64 ビット） ・ MIT ・ リポジトリ

β 版です。保存の形式や操作は、これから変わることがあります。大事なプロジェクトは、こまめにバックアップしてください。

0.0.1 のプロジェクトは 0.0.2 で開けますが、0.0.2 で保存したプロジェクトは 0.0.1 では開けません。

入れる

  1. リリース 0.0.2 β から NakkuntMovieMaker-0.0.2-beta-win-x64.zip（約 113 MB）を落とします。
  2. zip を展開して、NakkuntMovieMaker.exe を起動します。.NET を入れる必要はありません。

SHA-256: 43a7aeb4942cefa94d6a9cb6751a60e2fe4f3fbfa83f4afb83a5146657d44031

配っているのは Windows 版だけです。Linux・macOS（Apple Silicon）は、ソースからビルドすると、エンジンとコマンドラインでの書き出しまで使えます。

展開したフォルダの samples に、一般的な動画編集とゆっくり解説のサンプルプロジェクトがあります。

x264・x265 で書き出したいときは、自分で入手した ffmpeg を設定の「全般」で指定します（同梱の FFmpeg は、GPL の部品と x264 を含まないものです）。

GPU での描画と色

  • 合成・エフェクト 15 種類・トランジション 7 種類・文字と図形を、GPU（Vulkan）で描きます。使える GPU がないときや、正しく描けないときは、CPU で描きます。
  • 設定の「描画」で、描画の方式（自動・GPU・CPU）、使う GPU、GPU のメモリの上限を選べます。状態バーに、いまの描画の方式が出ます。
  • 書き出しも速くなりました。基準の PC で、10 分の動画の書き出しが実時間の約 3.9 倍の速さです（0.0.1 は約 2 倍）。Windows では、HEVC などの動画を GPU でデコードします。

GPU で描くには、Vulkan 1.2 以上に対応した GPU とドライバーが要ります（NVIDIA GeForce GTX 900 以降、AMD Radeon RX 400 以降、Intel 第 6 世代 Core の内蔵 GPU 以降など）。

色の管理

  • プロジェクトの設定で、合成の色空間（sRGB・リニア）、OpenColorIO の構成、書き出しの色空間を選べます。
  • 設定の「描画」で、プレビューを表示するモニターの色空間を選べます。
  • 素材の一覧の右クリックで、素材ごとの入力の色空間を選べます。HDR（PQ・HLG）の動画は、SDR にトーンマップして使います。

プロキシ編集

大きな動画の代わりに、編集用の軽い動画（プロキシ）をプレビューだけで使います。書き出しでは元の動画を使います。

  • 使う範囲（使わない・1080p より大きい動画だけ・すべての動画）は、プロジェクトの設定で選びます。
  • 作る・消すは素材の一覧の右クリック、プレビューでの切りかえは「表示」のメニューです。

セリフの読み上げ

セリフの読み上げには、同梱の ColorfulTalk（旧版）と、Windows の SAPI が使えます。

ColorfulTalk は漢字を読めません。漢字や英数字を含むセリフは、セリフ入力欄の「読み」に、カナとアクセント記号の記号列を入れてください。ひらがな・カタカナだけのセリフは、そのまま読みます。

きょ'うわ/い'い/てんきです。

記号列の書き方は ColorfulTalk のページにあります。

コマンドライン

同じフォルダの nmm.exe で、画面を出さずに書き出せます。

nmm export samples/general/general.nmmproj -o general.mp4 --preset youtube-1080p
nmm render-frame samples/yukkuri/yukkuri.nmmproj -f 1.5s -o frame.png
nmm proxy movie.mp4 -o movie.proxy.mp4

出力先の拡張子を .wav にすると、音声だけを書き出します。render-frame は 1 フレームを画像に、proxy はプロキシを作ります。export・render-frame では --renderer cpu のように描画の方式（auto・vulkan・cpu）を選べます。probe --gpu で使える GPU の一覧を、bench で性能を見られます。

わかっている制限

  • GPU での描画は、Intel Iris Xe（Windows）と、CI の Linux・macOS の仮想の GPU で確かめています。NVIDIA・AMD の GPU では、まだ確かめていません。
  • 動画を Vulkan Video でデコードする機能は、FFmpeg とドライバーの不具合で落ちることがあるので、試験的な機能として、ふだんは使いません（設定の「描画」で使えます）。
  • 立ち絵は、CPU で描いてから GPU に送ります。
  • 本物のマイクでの録音と、実際の立ち絵の素材での表示は、まだ十分に確かめていません。

README には、これから入れる予定の機能も書いてあります。いま入っているのは、上の「できること」のものです。

ソースからビルドする

.NET 10 SDK、PowerShell 7（Windows）か bash（Linux・macOS）、CMake（3.20 以上）と C・C++ のコンパイラ、FFmpeg のビルドに使うもの（Windows は MSYS2）が要ります。くわしくは README の「ビルドと実行」を見てください。

pwsh tools/fetch-native.ps1
pwsh tools/build-native.ps1

はじめてのときは、OpenColorIO のビルドに数分かかります。

dotnet build NakkuntMovieMaker.slnx
dotnet run --project src/NakkuntMovieMaker.App

Linux・macOS では ./tools/fetch-native.sh と ./tools/build-native.sh を使います。画面は Windows だけです。
