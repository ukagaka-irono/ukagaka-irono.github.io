伺かスタジオ（Ukagaka Studio）

伺か（SSP）のゴーストを、Scratch のようにブロックを積んで作るアプリです。組んだブロックは栞 YAYA の辞書に訳して書き出すので、書き出したものはふつうの YAYA ゴーストです。YAYA で手書きしたゴーストに、ブロックで作ったトークを足すこともできます。

リポジトリ ・ Releases ・ English ・ Windows 10 / 11 ・ なしライセンス 1.1

「なし栞 + なしスタジオ」（作者: 月見里 彩葉）のフォークです。名前を変えて、独自に直しています。2.0 からは、独自の栞をやめて YAYA を使っています。もとのものはこちら。

動く環境

  • 伺かスタジオ（ukagaka-studio.exe）: Windows 10 / 11。表示に Microsoft Edge WebView2 ランタイムを使います（Windows 11 には入っています）。
  • 書き出したゴースト: Windows 2000 以降。SSP の動作環境に合わせてあります。

exe は 1 ファイルで、ランタイムのインストールは要りません。

手に入れる

ふつうは Releases の zip を使います。押すたびの最新がほしいときは、Actions の実行ページのいちばん下の Artifacts にあります（GitHub のログインが要ります。30 日で消えます）。

コード署名していないので、Windows に止められることがあります。そのときは起動を止められたらを見てください。

起動する

ukagaka-studio.exe をダブルクリックします。はじめてなら「開く」→「お手本から始める」で、動くゴースト（あいさつ／好感度／時間で変わる／名前をきく／ゴースト間通信）を読みこんで中を見るのが早いです。

  • 保存していない変更は 1 分ごとに自動で保存します。保存のたびに上書き前のものを残すので、「開く」でプロジェクトの 🕘 から前の版を開けます。
  • 画面の言語は、上のバーの English／日本語 で切りかえられます。
  • ポートは開きません。外への通信は、SSP と話すときの 127.0.0.1:9801 だけです。

ブロックを組む

上のバーの「新規」で、ひな形ウィザードが開きます。ゴーストと 2 人の名前を入れて、はじめから入れておくもの（あいさつ・なでたときの反応・ランダムトーク・アラームなど）をえらびます。画面は、バーの下で トーク／セリフ／キャラと絵／ゴースト情報／書き出し に切りかえます。

  1. 「トーク」の画面で、左の「イベント」から「起動したとき」などをキャンバスにドラッグします。
  2. その下に「セリフ」の「◯◯が □□ と話す」をつなげます。欄の横の ☺ で、表情を変える印 {表情:1} や待つ印 {待つ:500} を入れられます。
  3. 右の「ためす」タブの ▶ で、しゃべる様子とさくらスクリプトを見ます。下に、いまの変数も出ます。
  4. 立ち絵は「キャラと絵」の画面で、用意した PNG を番号ごとに割り当てます。えらばなかった番号は、かんたんな立ち絵を自動で作ります。
  5. 「チェック」タブに、空のセリフ・無い変数・行き先のない選択肢などが出ます。赤い数字があったら、直してから書き出してください。

キー操作など

  • / で、ブロックを名前でさがして置けます。Enter で置いて、そのまま文字を打てます。キーボードだけで組めます。
  • Ctrl+F で、セリフや変数名からさがします。まとめて置きかえもできます。
  • Ctrl+C / Ctrl+V でブロックをコピーできます。別のプロジェクトにもはりつけられます。
  • 右クリックで、複製・部品にする・無効にする・メモ・たたむ・「YAYA を見る」などが出ます。
  • ? か F1 で、つかいかたとキーの一覧が開きます。

「部品」は、よく使う組みかたに名前を付けて取っておくものです。.parts.json にして人に渡せます。「YAYA を見る」では、そのかたまりがどんな YAYA の関数になるかを見られます。

SSP に入れる

「書き出し」の画面の「SSP に入れて動かす」を押します。

  • SSP の場所（ssp.exe）は自動で探します。見つからないときは、欄にパスを入れて「この場所を使う」。
  • SSP の ghost\ へ直接書き出して、そのゴーストに切り替えます。すでに動いていれば、栞だけ読み込み直します。
  • 「保存するたびに SSP に入れる」を入れておくと、Ctrl+S のたびに反映されます。

配るときは、同じ画面の「.nar を作る」です。できた .nar を SSP のウィンドウにドラッグ＆ドロップするとインストールできます。

動いているゴーストで試す

SSP とつながっていれば、「ためす」タブから、デスクトップで動いているゴーストで確かめられます。

  • SSPでしゃべらせる: いま選んでいるトークをしゃべらせる
  • イベント送信: 選んでいるイベント（OnMouseDoubleClick など）を送る
  • 話しかけてみる: ほかのゴーストのふりをして話しかける

SSP の「SSTP を受け付ける」（既定でオン）が有効になっている必要があります。

ネットワーク更新

  1. 「ゴースト情報」の「更新のありか」に、置き場所の URL を入れます。うしろに / を付けます（例: https://example.com/ghost/ikagako/）。
  2. 書き出すと、照合表の updates2.dau も一緒にできます。
  3. フォルダの中身を、その URL の場所にまるごとアップロードします。必ずバイナリモードで送ってください。
  4. 使う人は、右クリックメニューの「ネットワーク更新」で新しくなります。

md5 miss などでうまくいかないときは、アップロードするフォルダを SSP のウィンドウにドロップすると SSP が作り直してくれるので、それで上書きしてください。ファイルを消したいときは、置き場所に delete.txt を置きます。

手書きの YAYA に足す

  1. 「書き出し」の画面の「手書きの YAYA ゴーストにつなぐ」に、ゴーストのフォルダ（中に ghost\master があるもの）を入れて「つなぐ」を押します。
  2. つないでいるあいだは、書き出すとそのゴーストに書きこみます。書くのは studio_runtime.dic・studio_program.dic と、yaya.txt の印の付いた数行だけです。手書きの辞書には触りません。
  • 同じイベントは手書きが優先です。ブロックも動かしたいときは、手書きの関数の中で Studio.Event('OnBoot') をよびます。
  • ブロックの変数は、手書きの YAYA から Studio.var['名前'] で読み書きできます。

保存される場所

ukagaka-studio.exe と同じフォルダにできます。

場所中身
projects\プロジェクト
projects\.history\プロジェクトの前の版
output\書き出したゴースト（書き出し先を変えていないとき）
parts.json部品
ukagaka-studio.json最後に開いたプロジェクト・書き出し先・ウィンドウの大きさ・言語
webview-data\WebView2 の作業フォルダ（消しても作り直されます）

人からもらったプロジェクト（.json）は、開く前に中身を確かめてください。立ち絵はパスで指定されているので、書き出すとその画像がゴーストに入ります。

起動を止められたら

「アプリケーション制御ポリシーによってブロックされました」と出るのは、Windows 11 のスマートアプリコントロールが、署名のない exe を止めているためです。

  1. 少し待ってから、もう一度実行してみる（通ることがありますが、確実ではありません）。
  2. 公的な認証局のコード署名証明書で署名する。
  3. スマートアプリコントロールを切る（Windows セキュリティ →「アプリとブラウザーの制御」）。

スマートアプリコントロールは、一度オフにすると Windows を入れ直すまで戻せません。

自分でビルドするときは、Visual Studio の「C++ によるデスクトップ開発」を入れて、リポジトリで実行します。

.\build.ps1            # スタジオを作る
.\build.ps1 -Test      # テストも走らせる
.\build.ps1 -Release   # 配布用の zip を作る

ライセンス

なしライセンス 1.1 です（もとのプロジェクトの独自ライセンスで、許諾型）。だれでも無償で、目的を問わず、使う・直す・配ることができます。

書き出したゴーストを配るときは、ライセンス文の同梱も、作者名やソフト名の表記も要りません。有償で配ってもかまいません。

伺かスタジオそのもの（exe やソース）を配る・フォークするときは、LICENSE を一緒に入れて、変えたことと、もとのプロジェクトの場所と作者名がわかるようにしてください。くわしくは README の「ライセンス」を見てください。
