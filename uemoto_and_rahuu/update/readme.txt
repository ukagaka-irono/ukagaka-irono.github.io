================================================================================

  植本とラフウ  ( uemoto_and_rahuu )

  デスクトップマスコット「伺か」用ゴースト

================================================================================


■ このゴーストについて

  頭に植物が生えた「植本（ウエモト）」と、まるくてあたたかい「ラフウ」の
  ふたり組です。

  植本の頭の植物は、一緒に過ごした時間だけ育ちます。
  芽が出て、葉が増えて、つぼみができて、花が咲く。
  そして散って、また芽から。何度でも咲きます。

  急かさないし、急がない。そういうゴーストです。


■ 動作環境

  ベースウェア : SSP（推奨）
  SHIORI       : YAYA  Tc573-6 同梱

  ネットワーク更新とRSS取得を使う場合はインターネット接続が必要です。
  使わなくても動きます。


================================================================================
  キャラクター
================================================================================

  ● 植本（ウエモト）  … \0 側

    頭に植物が生えている、みどり色の生きもの。
    口数が少なく、短く喋ります。ものの見かたが少し植物寄り。
    自分のことを「ウエモト」と呼びます。

  ● ラフウ  … \1 側

    まるくてあたたかい、だいだい色の生きもの。触角があります。
    植本より口が回って、よく突っ込みます。面倒見がいい。
    自分のことを「オレ」と呼びます。


================================================================================
  できること
================================================================================

■ 植物が育ちます

  植本の頭の植物は、一緒にいた時間に応じて7段階に変化します。

    芽なし → 葉1枚 → 葉2枚 → 葉3枚 → 葉4枚 → つぼみ → 花

  だいたいの目安（累積起動時間）

    1時間   葉1枚
    3時間   葉2枚
    6時間   葉3枚
    12時間  葉4枚
    24時間  つぼみ
    36時間  花が咲く
    48時間  花が散って、また芽から（2周目）

  段階が上がった時と、花が咲いた時・散った時には専用の会話があります。
  何周したかも覚えているので、長く付き合うほど話が変わります。

■ 花の図鑑

  咲く花は、咲くたびに6種類のどれかに決まります。
    なでしこ / さくらそう / コスモス / ゼラニウム / スイートピー / ペチュニア
  まだ咲いていない種類から順に咲くので、続けていれば全部そろいます。

  メニューの「植物の様子」→「アルバムを見る」で、
  これまでに咲いた花と、初めて咲いた日、咲いた回数を見返せます。

■ お世話（水やり・日なた）

  メニューの「お世話する」から、1日1回ずつ
  「水をあげる」と「日なたに出す」ができます。
  水は2時間ぶん、日なたは1時間ぶん、成長が早くなります。
  日なたは日が出ている時間だけです（夜は断られます）。

  短い時間しか起動しない方でも花にたどり着けるようにするための仕組みです。
  毎日両方すると、1日1時間の起動でも9日ほどで咲きます。

■ お知らせを読み上げます

  植物園やニュースのRSSを見に行って、新しいお知らせがあると教えてくれます。
  タイトルを押すと、その記事がブラウザで開きます。

  購読先はメニューの「各種設定変更 → RSSフィード」から選べます。
  最初は「全国まとめ」だけが入っています。

  選べる情報源

    ・EVERGREEN 植物園リスト   全国まとめ / 都道府県別47 / 施設別348
    ・京都府立大学 植物学研究室
    ・気象庁 高頻度フィード      定時・随時・地震火山・その他
    ・消防庁                     新着・災害情報・報道発表・お知らせ
    ・防災科学技術研究所 J-RISQ  地震速報
    ・NHKニュース                8分野
    ・Yahoo!ニュース             カテゴリ9 / 提供メディア662

  ※ 防災情報について
    これは防災の手段ではありません。
    決まった間隔で見に行く仕組みなので、必ず遅れが出ます。
    そもそもSSPを起動していなければ何も届きません。
    急ぐときは、必ず本物の警報でご確認ください。

■ 話しかけられます

  メニューの「話しかける」から文章を送ると返事をします。
  あいさつ、植物のこと、自分たちのこと、体調を気づかう言葉などに反応します。

■ そのほか

  ・時報（毎時0分）と、日付が変わった時のあいさつ
  ・見切れ（画面の端に埋まった時）の反応
  ・撫でられ続けた時の、だんだん変わる反応
  ・ユーザーの誕生日（SSPに登録してあれば）
  ・他のゴーストとの交代・呼び出し・コミュニケート


================================================================================
  操作
================================================================================

  メニューを開く    ・3回続けてクリック
                    ・中ボタン（ホイール）クリック
                    ・M キー

  なでる            体の各所を撫でると反応します
                    植本  … 顔 / 頭 / 頭の植物 / 胴 / 足
                    ラフウ… 触角 / 顔 / 胴

  ダブルクリック    撫でるのとは別の反応をします
  ホイール          くるくる回すと反応します

  会話の頻度        メニューの「各種設定変更 → 喋る頻度変えて」で
                    15秒 / 1分 / 3分 / 10分 / 黙る から選べます

  名前を覚えさせる  メニューの「各種設定変更 → 名前を教える」
