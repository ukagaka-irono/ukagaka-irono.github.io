Maid Classic（フリーバルーン）
==============================

アイボリーの地にプラムの縁取り、金の点線フレームとローズのリボンをあしらった
メイド風クラシックバルーンです。SSP 向けに作成しています（32bit PNG の透過を使用）。

■ 収録
  balloons0〜3 : 本体側（0=通常 / 2=大きいサイズ、奇数は左右反転配置用）
  balloonk0〜3 : 相方側
  balloonc0〜3 : 3人目以降
  communicate0 / input0 : コミュニケート・入力ボックス
  arrow0/1, sstp, online0〜3 : 各種マーカー

■ インストール
  maid_classic.nar を SSP のキャラクターにドラッグ＆ドロップしてください。

■ 配布サイト
  https://ukagaka-irono.github.io/maid_classic/
  https://cherry.narnaloader.ukagaka.net/ghost.php?ghost=maid_classic
