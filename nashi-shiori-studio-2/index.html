なし栞 + なしスタジオ

伺か（SSP）用の栞（SHIORI）「なし栞」と、その栞を使うゴーストをブロックを積んで作るアプリ「なしスタジオ」の一式です。月見里 彩葉さんのなし栞 + なしスタジオのフォークで、伺かスタジオのもとになったものです。

リポジトリ ・ もとのリポジトリ ・ Windows 10 / 11 ・ なしライセンス 1.1

伺かスタジオとのちがい

使い方はほとんど同じです。ちがうのは、ゴーストが使う栞です。

なし栞 + なしスタジオ伺かスタジオ
アプリnashi-studio.exeukagaka-studio.exe
栞なし栞 nashi.dllYAYA yaya.dll
会話の入れ方ブロックのまま ghost.json に入れるYAYA の辞書に訳して書き出す
手書きの辞書と混ぜるできないできる

動く環境は、なしスタジオが Windows 10 / 11（WebView2 が要ります）、なし栞と書き出したゴーストが Windows 2000 以降です。

手に入れる

このフォークには Releases がありません。もとのリポジトリの Releases か Actions（ログインが要ります）を見てください。Actions の Artifacts には、スタジオ一式の nashi-studio-… と、栞だけの nashi-dll-… があります。

自分でビルドするときは、Visual Studio の「C++ によるデスクトップ開発」を入れて .\build.ps1 を実行します。署名していない exe が止められたときは、伺かスタジオのページと同じように対処してください。

使い方

  1. nashi-studio.exe をダブルクリックします。はじめてなら「開く」→「お手本から始める」が早いです。
  2. 左の「イベント」から「起動したとき」などをドラッグして、その下に「セリフ」の「◯◯が □□ と話す」をつなげます。
  3. 右の「ためす」タブの ▶ で、しゃべる様子を見ます。
  4. 「ゴースト」タブの「立ち絵の画像」で PNG を割り当て、「うごき」でアニメーションを作ります。
  5. 「チェック」タブの赤い数字を直します。
  6. 「書き出し」タブの「SSP に入れて動かす」で SSP に入れます。配るときは「.nar を作る」です。

SSTP 連携とネットワーク更新（「ゴースト」タブの「更新のありか」）も、伺かスタジオと同じように使えます。SSP を動かしたまま書き出し直すと、栞が数秒で ghost.json を読み直します。

プロジェクトなどは、nashi-studio.exe と同じフォルダの projects\・output\・nashi-studio.json に保存されます。exe のとなりに nashi.dll を置くと、埋め込みのものよりそちらが使われます。

なし栞のしくみ

  • SHIORI/3.0 の DLL（32bit）です。起動時に、DLL と同じフォルダの ghost.json を読み込みます。
  • SSP から来たイベントに合うブロックを実行して、さくらスクリプトを返します。
  • ランダムトークは、直近に出したものを候補から外します。
  • 変数は、終了時と 2 分ごとに nashi_save.json に保存されます。
  • OnMouseMove が同じ場所で続くと、独自の OnNadeNade（なでられたとき）を作ります。SSP にはないイベントです。
  • ゴースト間通信（OnCommunicate）と SAORI に対応しています。

SSP なしで試す

.\build.ps1 -Test
.\shiori\dist\test_host.exe .\output\なしちゃん\ghost\master OnBoot OnMouseDoubleClick:0,0,0,0,Head OnClose

イベント名:参照0,参照1,... の形で並べます。OnSecondChange:0,1*200 のように *回数 を付けるとくりかえせます。
