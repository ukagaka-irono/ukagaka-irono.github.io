tama v6（tama-v6）

YAYA / AYA の SHIORI がちゃんと動くかを確かめ、実行ログをその場で表示するツールです。ゴーストを起動したまま横に置いておけば、辞書のエラーや警告がすぐに分かります。ログを出してすぐ終わるコマンドライン版の tamac も入っていて、CI や AI に辞書のエラーを見せるのにも使えます。YAYA-shiori/tama を引き継いで手を入れている版です。

tama.exe ・ tamac.exe ・ リポジトリ ・ Releases ・ v1.0.3.28（2026年11月3日） ・ Windows

手に入れる

使うものを落として、好きな場所に置くだけで動きます。インストールは要りません。

ファイル内容
tama.exe（43 KB）ログを表示するウィンドウの tama。UPX で縮めてあります
tama_NUPX.exe（94 KB）縮めていない tama。中身は tama.exe と同じです
tamac.exe（76 KB）コマンドライン版。辞書を 1 回読んで、ログを出して終わります

ウイルス対策ソフトが tama.exe のダウンロードや起動を止めるときは、tama_NUPX.exe を使ってください。UPX で縮めた実行ファイルは、誤って検出されることがあります。

同じファイルを Releases でも配っています。自分でビルドするときは、Visual Studio（C++ のデスクトップ開発）で tama.sln を開きます。

git clone --recursive https://github.com/ukagaka-irono/tama-v6.git

使い方

  • SSP でゴーストを起動しておいて、tama.exe を開きます。動いているゴーストが 1 体なら、そのゴーストのログを表示します。何体か動いているときは、選ぶ画面が出ます。
  • ゴーストを決めて開くときは、名前か、ゴーストのウィンドウハンドルを渡します。
tama.exe -g ゴースト名
tama.exe -gh ゴーストのウィンドウハンドル
  • 辞書のどこが間違っているかだけ知りたいときは、yaya.dll（または aya.dll）を tama のウィンドウにドラッグ＆ドロップします。tama がその場で読みこんで、エラーを表示します。
  • ウィンドウの位置や文字の色・フォントは tama.txt に保存されます。ゴーストを決めて開いたときはゴーストの profile\tama.txt、そうでないときは tama.exe と同じ場所の tama.txt です。表示は日本語・中国語・英語に対応しています。

ウィンドウを右クリックすると、次のメニューが出ます。

メニューすること
最初の行へ移動・最後の行へ移動ログの先頭・末尾に飛ぶ
クリップボードにコピーする選んだログをコピーする（Ctrl+C）
ログ受信ログを受け取るかどうかを切りかえる
SHIORIの所有権の自動譲渡無効ゴーストの SHIORI がエラーで止まったとき、tama が代わりに読みこむのをやめる
リクエスト送信パネルを開くSHIORI に送る要求文を書いて送る
リロード・アンロードSHIORI を読みこみ直す・外す

tamac（コマンドライン）

tamac.exe は、YAYA を 1 回読みこんでエラーを調べ、ログを出してすぐ終わります。エラーがあれば、終了コードが 0 以外になります。

tamac.exe yaya.dll
tamac.exe yaya.dll -l [fatal|error|warning|note]
tamac.exe yaya.dll --ci
  • -l で、どの重さからをエラーとして扱うかを決めます。
  • --ci を付けるか、環境変数 GITHUB_ACTIONS があると（GitHub Actions の上では自動で）、エラーを GitHub Actions の注釈（::error file=... など）で出します。PR の差分の上に、エラーの場所が出ます。出力は yaya-CI-check と同じ形です。
  • -r（--request）を付けると、標準入力を最後まで読んで SHIORI の要求文として YAYA に送り、応答を標準出力に出して終わります。改行は CRLF にそろえ、終わりの空行も足します。ログはすべて標準エラー出力に出るので、標準出力は応答だけになります。
tamac.exe yaya.dll -r < request.txt

ゴーストから tama を使う

tama が開いたときと閉じたときに、ゴーストにイベント tamaOpen・tamaExit が届きます（YAYA の辞書では On_tamaOpen・On_tamaExit に書きます）。Reference0 は tama のウィンドウハンドルです。ここで SETTAMAHWND を呼ぶと、ゴーストのログが tama に出ます。開いても何も出ないときは、この 2 つを辞書に足してください。

On_tamaOpen{
	SETTAMAHWND(reference[0])
	SHIORI3FW.Push_X_SSTP_PassThru('Title','tama test')//ここから下の設定は書かなくても構いません
	SHIORI3FW.Push_X_SSTP_PassThru('border.color','626262')
	SHIORI3FW.Push_X_SSTP_PassThru('background.color','1e1e1e')
	SHIORI3FW.Push_X_SSTP_PassThru('default.color','4ec9b0')//ほかの設定は tama.txt にあります
	'tama が開きました'
}
On_tamaExit{
	SETTAMAHWND(0)
	'tama が閉じました'
}

tama のウィンドウハンドルを変数に入れておき、SHIORI を読みこみ直したあとに SETTAMAHWND をもう一度呼べば、リロードしても tama とつながったままにできます。yaya-dic の新しい版には、もう入っています。

On_tamaOpen{
	TamaHwnd=reference[0]
	//...
}
On_tamaExit{
	ERASEVAR('TamaHwnd')
	//...
}
OnInitialize{
	if reference[0]=='reload'
		SETTAMAHWND(TamaHwnd)
	//...
}

更新履歴

  • v1.0.3.28（v6 から）: 「新しい版があります」のお知らせが、tama v6 のリリースを見るようになりました。「はい」を押すと、このページを開きます。
  • v1.0.3.27（v6 から）: 新しい YAYA（Tc571-10 以降）の loadu に対応しました。日本語の Windows で、ハングルなど Shift_JIS にない文字を含むフォルダのゴーストも読みこめます。
  • v1.0.3.27（v6 から）: ログが長くなったとき、古い行を早めに消しすぎていたのを直しました。
  • v1.0.3.26: tamac -r で、長い要求文の中の日本語などが壊れることがあったのを直しました。
  • v1.0.3.25: tamac に -r（--request）を足しました。
  • v1.0.3.24: tamac に --ci を足しました。

v1.0.3.27 までの tama は、「新しい版があります」のお知らせに本家（YAYA-shiori/tama）のリリースを見ています。v1.0.3.27 を使っている方は、このページから v1.0.3.28 を入れ直してください。そこから先は、v6 の新しい版が出るとお知らせが届きます。
