ColorfulTalk

小さな機器でも気軽に動かせる、無料（MIT ライセンス）の日本語音声合成エンジンのシリーズです。録音した声を使わない規則合成（フォルマント合成）なので、声データのライセンスを気にせず組み込んで配れます。

ColorfulTalkPlayer

ColorfulTalk の公式の読み上げアプリです。文章を読み上げたり、WAV ファイルに書き出したりできます。

  • 漢字かな交じり文をそのまま読み上げます（ColorfulYomi で読みとアクセントを付けます）。変換した記号列を見て、直してから読み上げることもできます。
  • エンジン 4 種（V3・V2・V1・nano）、声 31 種。話速・音量、V3 では声の高さ・抑揚・声質もスライダーで変えられます。
  • 設定のプリセット、ユーザー辞書、WAV の保存（44.1kHz・48kHz への変換も）。
  • 音声は使っている機器の中で作り、外には送りません。

Web 版を開く（入れなくても、ブラウザだけで動きます。はじめは辞書 26MB を読み込みます）

Windows・Mac 版は、リリース 1.0.0 から落とします。

ファイル対象
ColorfulTalkPlayer_1.0.0_x64-setup.exeWindows（インストーラー、約 9 MB）
ColorfulTalkPlayer_1.0.0_universal.dmgMac（約 18 MB）

署名していないので、はじめて起動するときに警告が出ます。Windows・Mac 版はコマンドラインからも読み上げられます。

ColorfulTalkPlayer -t "今日はいい天気です。" -o out.wav -v v3:f1 -s 1.2

しくみ

音声合成エンジンは辞書を持たず、読みとアクセントを書いた「記号列」を受け取って音にします。漢字かな交じり文を読ませるときは、言語処理エンジン ColorfulYomi で記号列に変えてから渡します。

漢字かな交じり文 → ColorfulYomi（辞書を使う）→ カナ記号列 → V1 / V2 / V3 → 音声
                                         └→ ローマ字記号列 → nano / pico LSI → 音声

記号列の書き方

読みをカナで書き、アクセントの下がり目（アクセント核）のあとに ' を、句の区切りに / 、 。 ？ を書きます。V1・V2・V3 は同じカナ記号列を使います。

こんにちわ、せか'い。
きょ'うわ/い'い/てんきです。
ほんとうに/そ'うですか？

nano と pico LSI は、同じ決まりをローマ字で書きます（kyo'uwa/i'i/teNkidesu.）。くわしくは V3 の カナ記号列の書き方 と、nano の ローマ字記号列の書き方 にあります。

ColorfulTalk V3

シリーズでいちばん新しく、いちばん自然で聞き取りやすい声のエンジンです。声質をパラメータで変えられます。

  • 出力は 16bit PCM、モノラル、16kHz（8〜48kHz に変えられます）。
  • 作業領域は約 15KB、動的メモリは使いません。単精度浮動小数点だけを使うので、FPU のある Cortex-M4F や ESP32、PC で動きます。
  • 声は女声・男声・子どものプリセット。声の高さ・声道の長さ・張り・息っぽさ・ゆらぎ・抑揚・話速・音量を指定できます。

Windows 用のビルド済みのもの（ライブラリと試聴用の ctalk）は リリース 3.0.0 にあります。

ctalk -v m1 -s 1.2 -o hello.wav "きょ'うわ/い'い/てんきです。"

組み込み方やビルドは ColorfulTalk-V3 の README を見てください。

ColorfulTalk V2

声を決める小さなデータ（.ctv、1 つ 212 バイト）を差しかえて、動いているあいだに声を切りかえられるエンジンです。

  • 整数演算だけで動きます。int が 16bit の CPU でも PC と同じ音が出ます。
  • ROM 約 24KB、RAM 約 4.7KB。出力は 16bit PCM、8kHz、モノラル。
  • 14 種類の声データ入り（女声 5・男声 4・子ども 2・年配・ささやき・ロボット）。mkvoice で自分の声も作れます。

ビルド済みのものは リリース 2.0.0、くわしくは README にあります。

ColorfulTalk V1

声を 1 種類だけ組み込んだ、小さな構成のエンジンです。

  • 整数演算だけで動きます。ROM 約 24KB、RAM 約 5.4KB。出力は 16bit PCM、8kHz、モノラル。
  • 声はビルドするときに 1 種類を選びます。標準は女声 F1 で、ほかに 9 種類あります。

ビルド済みのものは リリース 1.0.0、くわしくは README にあります。

ColorfulTalk nano

シリーズでいちばん小さいエンジンです。RAM 約 200 バイト・ROM 約 8KB で、8bit CPU でもリアルタイムに話します。

  • ATmega328P（16MHz）で、8kHz の実時間に収まります。表はすべて ROM に置きます。
  • 入力はローマ字の記号列。出力は 8kHz の 16bit か、PWM にそのまま使える 8bit。
  • 声は 4 種類（女声・男声・子ども・ロボット）。

ビルド済みのものは リリース 1.0.0、くわしくは README にあります。

ColorfulTalk pico LSI

nano を ATmega328P（Arduino Uno と同じチップ）に載せた、1 チップの音声合成 LSI の設計図です。ファームウェア・回路図・部品表がそろっています。

  • UART（9600bps）か I2C（0x2E）で記号列を 1 行送ると話します。話し終わると > を返し、BUSY ピンも下がります。
  • 音声は PWM で出し、RC フィルタとアンプでスピーカーを鳴らします。部品は 10 点ほどです。
  • シミュレータで動作を確かめています。I2C と実機での動作は、まだ確かめていません。

作り方は ColorfulTalk-picoLSI の README にあります。

ColorfulYomi と Colorful-dictionary

ColorfulYomi は、漢字かな交じり文を記号列に変える言語処理エンジンです。

今日はいい天気ですね。
→ きょ'ーわ/い'い/て'んきですね。      （V1 / V2 / V3 用）
→ kyo'-wa/i'i/te'Nkidesune.            （nano / pico LSI 用）
  • 約 48 万語の辞書（Colorful-dictionary）で、読み・アクセント・句の区切りを決めます。日常文 100 文で、読みの一致率は 97% です。
  • 数・日付・助数詞の音の変化（3本・6分・1人）・英字も読みます。ユーザー辞書（CSV）で読みとアクセントを足せます。
  • C99 で、ほかのライブラリは使いません。コマンド cyomi もあります。

辞書ファイル colorful_talk.dic（26MB）は Colorful-dictionary のリリース（版 1） から落とします。辞書を同梱して配るときは、辞書の NOTICE もいっしょに入れてください。くわしくは ColorfulYomi と Colorful-dictionary の README にあります。

旧版（colorful-talk）

シリーズの前に作った 1 本のエンジン colorful-talk は、更新を終えて読み取り専用にしています。いまは NakkuntMovieMaker に同梱して使っています。新しく使うときは、V3 などのシリーズを使ってください。
